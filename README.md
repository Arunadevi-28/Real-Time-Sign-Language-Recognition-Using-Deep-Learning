# Real-Time Sign Language Recognition Using Deep Learning

A Python-based sign language gesture recognition system that supports dynamic gesture data collection, deep learning model training, and real-time gesture prediction. The project includes scripts for collecting gesture samples, training a recognition model, and predicting supported gestures using saved model files and label mappings.

## **Overview**

Sign language gesture recognition is an important application of computer vision and machine learning that aims to support accessible communication.

This project provides a complete workflow for collecting dynamic gesture data, training a recognition model, and performing real-time gesture prediction. It uses saved model files and label mappings to associate predictions with the gestures represented in the training dataset.

## **Features**

- **Dynamic Gesture Data Collection:** Collect gesture samples for model training.
- **Deep Learning Model Training:** Train a gesture recognition model using collected data.
- **Real-Time Gesture Recognition:** Predict supported gestures through the real-time recognition script.
- **Saved Model Support:** Load trained models for inference.
- **Gesture Label Mapping:** Associate model predictions with their corresponding gesture labels.
- **Data Processing:** Store and process gesture samples and labels.
- **Modular Workflow:** Separate scripts for data collection, model training, and real-time prediction.

## **Installation**

### **Prerequisites**

- Python installed on your system.
- pip package manager.
- A webcam, if required by the real-time recognition script.
- The required model and label files, if inference depends on saved assets.

### **1. Create a Virtual Environment**

**Windows:**

```bash
python -m venv .venv
```

Activate the environment:

```bash
.venv\Scripts\activate
```

**Linux/macOS:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### **2. Install Dependencies**

Upgrade pip:

```bash
python -m pip install --upgrade pip
```

Install the project dependencies:

```bash
pip install -r requirements.txt
```

Use dependency versions compatible with your Python version and the libraries imported by the project.
